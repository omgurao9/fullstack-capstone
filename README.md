# Cars Dealership — Full-stack Capstone


A starter implementation for the Cars Dealership full-stack capstone. It uses Django, SQLite, Django templates, a React registration component source file, REST-style JSON endpoints, Docker, and GitHub Actions.

## Important
This repository contains application code and reproducible instructions. Assessment evidence must be generated by running the application yourself: terminal outputs, browser screenshots, GitHub URLs, and a real deployment URL are environment-specific and must not be fabricated.

## Requirements
- Python 3.12 recommended (Python 3.14 may not yet be supported by every dependency)
- Git
- Optional: Node.js 20+ for the React component/build work
- Optional: Docker

## Windows setup (PowerShell)
```powershell
cd fullstack-capstone
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_dealers
python manage.py createsuperuser
python manage.py runserver
```
Open http://127.0.0.1:8000/ for the app and http://127.0.0.1:8000/admin/ for Django admin.

## Demo account
For local demo only, the seed command creates `demo_user` with password `DemoPass123!` if it does not already exist. Change/remove this account before public deployment. Never use this password for a real account.

## Main pages
- `/` home/dealer list
- `/about/` About Us
- `/contact/` Contact Us
- `/register/` sign-up form
- `/login/` login form
- `/logout/` logout
- `/dealer/<dealer_id>/` dealer details and reviews
- `/review/<dealer_id>/` post a review
- `/admin/` Django admin

## JSON API endpoints
- `POST /api/login/` JSON `{ "username": "...", "password": "..." }`
- `POST /api/logout/`
- `GET /api/dealers/`
- `GET /api/dealers/<dealer_id>/`
- `GET /api/dealers/<dealer_id>/reviews/`
- `GET /api/dealers/state/<state>/` (e.g. `/api/dealers/state/Kansas/`)
- `GET /api/carmakes/`
- `POST /api/analyze-review/` JSON `{ "review": "Fantastic services" }`
- `POST /api/register/` JSON with `username`, `first_name`, `last_name`, `email`, `password`

For session-authenticated POST requests from curl, first obtain the CSRF cookie and submit its token. See `docs/curl-examples.md`.

## Seed data
```powershell
python manage.py seed_dealers
```
The command creates demo dealers, car makes/models, and a few sample reviews idempotently.

## Tests
```powershell
python manage.py test
```

## Docker
```bash
docker build -t cars-dealership-capstone .
docker run --rm -p 8000:8000 cars-dealership-capstone
```
The container runs migrations and seeds demo data on startup. SQLite is suitable for a demo, not a horizontally scaled production deployment.

## GitHub Actions
The workflow at `.github/workflows/django.yml` installs dependencies and runs Django tests on pushes and pull requests.

## Deployment
See `docs/deployment.md`. For a real deployment, set `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=False`, `DJANGO_ALLOWED_HOSTS`, and configure persistent database storage or PostgreSQL. The app has not been deployed by this generated project, so the assignment's deployment URL and deployed screenshots must be captured after you deploy it.
